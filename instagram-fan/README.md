# Instagram Fan Site (Mock)

這個資料夾對應的是為展覽拍攝使用的「模擬 Instagram 網站」。

- 目的：在拍攝作品時，用來取代真實 Instagram 畫面，避免實際帳號與隱私問題，並可以自由控制內容。
- 技術堆疊：以純 HTML/CSS/JavaScript 寫成靜態頁面，模擬 Instagram 的基本版面與貼文樣式。
- 佈署方式：放在 ESXi 虛擬機上的 web server 中，透過 Docker 或簡單的 Nginx 服務對外提供。
- 使用情境：在拍攝過程中於螢幕上顯示，由同學操作模擬帳號與貼文，讓畫面更貼近實際社群使用情境，同時維持可控與安全。
